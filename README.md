# RECALL

RECALL is a simple and modern memory app that lets you save, search, and manage personal notes directly in your browser.

## Features

- Create memories
- Search memories
- Delete memories
- Automatic local storage
- Responsive design
- Dark Web3-inspired interface
- No backend required
